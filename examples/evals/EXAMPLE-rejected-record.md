# Rejected — example-generic-dashboard

- **date**: 2000-01-01
- **tier**: 3
- **surface / scope**: EXAMPLE ONLY — shipped to show the rejection format.

## Why it was rejected

EXAMPLE: a generic AI-SaaS result. Every section was a rounded card, a purple gradient
hero led the page, filters were pills, and the data table was buried in a card grid.
The operator could not see what changed without scrolling.

## Failure signals

- `excessive-cards`
- `gradient`
- `pill-heavy`
- `marketing-title`
- `data-buried`

## The correct move instead

EXAMPLE: return to the Design Director. Re-derive surfaces from spacing and hairline
borders, promote the table to the primary surface, and reserve the accent for
selection and the one committed action.
