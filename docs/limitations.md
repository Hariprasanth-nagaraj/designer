# Limitations and honest claims

- Designer orchestrates an agent; it is not a new model, studio or UI framework.
- Deterministic source checks are heuristics: they do not prove semantic token usage
  everywhere, WCAG conformance, component uniqueness, taste or task success.
- Brand/archetype clinical and CRM coverage is thin; the bundled product-type prior
  enriches context but is not research about your users.
- Complete upstream methodology/search is opt-in. Python/git/network and Linux
  browser system dependencies can be unavailable; report that explicitly.
- Setup does not configure MCP, replace agent settings, or certify every placement.
- Interrupted installs may retain recovery backups; review them rather than deleting
  blindly. Concurrent updates to one destination are unsupported.
- The earlier 1.1.0 CI matrix was observed successful on Windows/macOS/Linux.
  Current-release CI status must be checked after publication/push; do not infer it
  from an updated workflow file.
- Meridian flow/audit parity is one benchmark, not independent/blind validation or
  equal taste across all six briefs and models.
- Full doctor readiness includes native discovery and MCP evidence it cannot obtain
  merely by reading directories. PARTIAL is intentional, not a disguised PASS.
